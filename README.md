# Machine Learning Projects

This repository showcases a collection of **Machine Learning & AI-Based Classification Projects** that I have worked on. Each project applies different machine learning techniques for **predictive modeling, classification, and optimization**.

---

## Projects Overview

### 1. Housing Price Prediction ([Project Files](./Housing%20Price%20Prediction))
- Developed a **regression model** to predict housing prices.
- Optimized **RMSLE scores** through **feature selection and hyperparameter tuning**.
- Applied **Lasso, Ridge Regression, and Decision Trees** for better accuracy.

### 2. Sentiment Analysis ([Project Files](./Sentimental%20Classification))
- Built a **text classifier** using **word2vec, perceptron, and k-NN**.
- Evaluated model performance and achieved an **error rate of ~22.4%**.
- Applied **feature pruning** and **TF-IDF** for better text representation.

### 3. Document Classification ([Project Files](./Document%20Classification))
- Implemented **logistic regression and k-NN** for **document categorization**.
- Used **TF-IDF vectorization** to extract meaningful features from text.
- Evaluated models using **accuracy and confusion matrices**.

### 4. Binary Classification ([Project Files](./Binary%20Classification))
- Applied **perceptron algorithms** for **binary text classification**.
- Explored **feature pruning techniques** to improve classification accuracy.
- Tuned **hyperparameters** to minimize classification error.

### 5. Model Optimization ([Project Files](./Document%20Classification), [Project Files](./Sentimental%20Classification))
- Fine-tuned **machine learning models** with **train-dev-test splits**.
- Performed **hyperparameter tuning** using **grid search & cross-validation**.
- Focused on model performance and generalization.
